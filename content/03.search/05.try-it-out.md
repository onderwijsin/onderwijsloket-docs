# Try it out

You can experiment with our Algolia Search instance using a sandbox API key.

This allows you to explore and test the search engine **without requesting additional permissions**.

## Sandbox

The sandbox token provides **query** and **browse** access to all indexes, while usage limits are enforced to prevent misuse.

```plaintext
<TOKEN_WILL_BE_DISPLAYED_HERE>
```

### Usage Limits

The sandbox token has the following restrictions:

- The token **rotates every hour**

- Up to **60 API calls per IP address per hour**

- A maximum of **10 hits per query**

You can use this token to test queries against the available indexes and explore how the search API behaves under standard conditions.

## Real world examples

Want to see what the Search Engine looks like when not restricted? You can find various examples on our webplatform onderwijsloket.com. For example:

- Using a single index query: [search through our articles](https://onderwijsloket.com/kennisbank/artikelen)

- Using a multi index query: try our [global search feature](https://onderwijsloket.com/kennisbank/artikelen) (hit `CTRL + K` from any page)
