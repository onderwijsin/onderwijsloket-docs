# OpenAPI reference

The OpenAPI parsing, generated API records, search integration, and Scalar links are implemented by
the [docus-plus layer](https://github.com/onderwijsin/docus-plus). This application only supplies
the site-specific configuration and source values consumed by that layer.

When changing the OpenAPI source or its generated contract, consult the layer documentation first.
Keep Onderwijsloket-specific API usage examples in the published articles under `content/docs/`.
